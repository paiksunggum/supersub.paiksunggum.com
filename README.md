# Super-Sub 개발 제안서 사이트 (포트폴리오 사본)

**Super-Sub** 는 생활체육 경기 영상에서 선수의 실력을 재고, 그 근거로 팀이 빈 자리에
맞는 용병을 찾는 플랫폼입니다. **4인 팀 프로젝트**(2026.08.20 ~ 2026.10.27)이고,
이 저장소는 팀이 함께 만든 제안서 사이트를 **백성검이 포트폴리오용으로 복사**한
것입니다.

- 공개 주소 — <https://supersub.paiksunggum.com>
- **원본 사이트** — <https://dev.supersub-ai.com>
- **원본 저장소** — <https://github.com/pmhllll12/super-sub.cloud>
- 제품 웹 — <https://supersub-ai.com>

## 내 역할

이 사본에는 **[「내 역할」 페이지](https://supersub.paiksunggum.com/내-역할/)** 를
하나 더했습니다. 나머지 페이지는 팀 문서 그대로입니다.

저는 **Flutter 앱 전체와 Next.js 웹 대부분**을 맡았습니다.

| | |
|---|---|
| Flutter 앱 | 159개 파일 · 33,432줄 · 시험 994개 · 커밋 111/114 |
| Next.js 웹 | 308개 파일 · 54,411줄 · 커밋 392/482 |
| 전체 커밋 | 628개 (팀 전체 약 1,840개 중 최다) |

코드 전체는 [paiksunggum/super-sub.cloud](https://github.com/paiksunggum/super-sub.cloud)
에 있습니다 (팀 저장소 사본, 제 작업 브랜치는 `paik`).
