## 2.1 생활체육 용병 구인 현황

### 구인 절차

현재 동호회가 용병을 구하는 절차는 대체로 다음 순서를 따른다.

1. 경기 2~3일 전 참석 인원을 확인한다.
2. 결원이 확인되면 총무 또는 운영진이 구인 글을 작성한다.
3. 오픈채팅방·지역 카페 등 **여러 창구에 같은 글을 반복 게시한다.**
4. 응답자가 나타나면 개별 대화로 실력·포지션·참가비를 조율한다.
5. 경기 당일 현장에서 처음 대면한다.

### 현황의 특징

| 항목 | 현재 상태 |
|---|---|
| 정보 채널 | 분산. 채팅방·카페·지인으로 흩어져 통합 검색이 불가능하다 |
| 소요 시간 | 게시부터 확정까지 수 시간~수 일. 당일 결원은 대응이 어렵다 |
| 실력 정보 | 자기 신고에 의존한다. 검증 수단이 없다 |
| 보유 영상 | 촬영된 영상은 있으나 개인 소장에 그친다. 실력 근거로 쓰이지 않는다 |
| 기록 | 남지 않는다. 같은 사람과 다시 만나도 이전 이력을 알 수 없다 |
| 책임 | 불참해도 제재가 없다. 익명에 가깝다 |

구인은 **매번 처음부터 다시 시작된다.** 축적되는 것이 없다는 점이 현 방식의 핵심적인
문제다.

## 2.2 기존 서비스의 한계

기존에도 생활체육 매칭을 다루는 서비스가 있으나, 용병 구인 문제를 직접 해결하지는
못한다. 유형별 한계는 다음과 같다.

| 유형 | 성격 | 한계 |
|---|---|---|
| 소셜 매치 서비스 | 운영사가 경기를 열고 개인이 참가 신청한다 | 이미 존재하는 **동호회의 결원**을 메우는 용도가 아니다. 팀 단위 수요를 다루지 않는다 |
| 팀 매칭 서비스 | 팀 대 팀 경기를 연결한다 | 개인 단위 결원 문제는 대상이 아니다 |
| 오픈채팅·커뮤니티 | 자유 게시로 구인한다 | 검색·필터·이력이 없다. 실력 정보가 전무하다 |
| 종합 예약 플랫폼 | 경기장 예약이 중심이다 | 사람을 구하는 문제는 사용자에게 맡긴다 |
| **영상 분석·AI 코칭 앱** | 개인의 자세를 분석해 교정을 안내한다 | **분석 결과가 개인 훈련용으로 닫혀 있다.** 팀을 구하거나 사람을 고르는 데 쓰이지 않는다 |

> 확인 필요 — 개별 서비스명·기능 비교는 4.2에서 실제 서비스를 조사해 표로 확정한다.

정리하면 시장은 두 갈래로 나뉘어 있다. **매칭 서비스는 실력을 모른 채 사람을 연결하고,
영상 분석 서비스는 실력을 분석하되 그 결과를 혼자 보는 데서 끝난다.** 둘을 잇는 서비스,
즉 **분석된 실력 정보를 근거로 사람을 연결하는 서비스가 없다.**

영상 자체를 주고받는 방식도 대안이 되지 못한다. 구인자가 지원자의 경기 영상을 받는다
해도, 수십 분짜리 영상을 여러 명분 확인하고 자기 팀과 맞는지 판단하는 일은 현실적으로
불가능하다. **영상은 요약되고 지표화되어야 판단 근거가 된다.**

## 2.3 해결 과제

앞의 현황과 한계에서 다음 네 가지 과제를 도출한다. 각 과제는 3장의 기능과 대응한다.

| 과제 | 내용 | 대응 (3장) |
|---|---|---|
| **P1. 탐색 비용** | 구인자가 다수 채널을 직접 돌며 사람을 찾는다 | 적합도 기반 후보 추천 (3.4) |
| **P2. 실력 정보 부재** | 상대의 실력을 사전에 확인할 근거가 없다 | **영상 분석 기반 실력 지표 (3.3)** |
| **P3. 판단 비용** | 영상이 있어도 여러 명분을 직접 보고 판단할 수 없다 | 분석 리포트·특징 요약 (3.3) |
| **P4. 적합성 판단** | 실력을 알아도 우리 팀 스타일과 맞는지는 별개다 | 적합도 산출 (3.4) |
| **P5. 책임 부재** | 노쇼·지각에 대한 제재 수단이 없다 | 상호 평가 반영 및 이용 제한 (3.2) |

이 가운데 **P2·P3·P4가 본 사업의 핵심**이다. P1(탐색)은 매칭 기능만으로도 일부
해소되지만, 실력 정보가 없으면 매칭 결과를 신뢰할 수 없어 서비스가 기존 채팅방과 다를
바 없어진다. 반대로 분석만 있고 매칭이 없으면 기존 AI 코칭 앱과 다를 바 없다.
따라서 **영상 분석과 매칭을 하나의 절차로 결합**하는 것이 본 사업의 설계 전제다.
